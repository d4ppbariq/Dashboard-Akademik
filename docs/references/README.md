# Folder Referensi - DRAFT 4 PROPOSAL CAPSTONE PROJEK

Folder ini menampung berkas referensi terbuka (open access) yang dipakai pada dokumen `docs/DRAFT4_Proposal_Capstone.md` dan `docs/docx/DRAFT 4 PROPOSAL CAPSTONE PROJEK.docx`.

Seluruh referensi di bawah telah **diverifikasi valid** (PDF terunduh atau tautan web resmi). Referensi dari draf sebelumnya yang gagal diverifikasi/diunduh (mis. artikel Wiley tertentu, ScienceDirect, ACM, ResearchGate, serta sejumlah artikel yang PDF-nya terblokir) tidak dicantumkan. Dokumen internal tim pengembang (PRD, ML Roadmap, Protokol A1) sengaja **tidak** dimasukkan ke daftar pustaka pada DRAFT 4; informasinya dianggap sudah diketahui dan dikutip secara netral di teks.
